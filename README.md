# متابع الدراسة

تطبيق ويب خفيف لتسجيل جلسات الدراسة اليومية، مبني بـ HTML/CSS/JavaScript خام مع Supabase للحسابات وقاعدة البيانات. يُنشر مجانًا عبر GitHub Pages ويعمل كتطبيق منصّة (PWA) على الهاتف.

## المزايا

- تسجيل الدخول وإنشاء حساب بالبريد، مع **استعادة كلمة المرور** عبر رابط يصلك بالبريد.
- إضافة جلسات الدراسة بتاريخ اليوم أو أي **تاريخ سابق** (مادة + مدة + ملاحظة).
- **مؤقّت دراسة** يملأ حقل المدة تلقائيًا عند الإيقاف.
- **هدف يومي** قابل للتعديل مع شريط تقدم يحدّه بحسب إنجازك.
- عرض الجلسات بالتبويبات: اليوم / أمس / آخر ٧ أيام / هذا الشهر، مع **تصدير CSV**.
- **مخطط أسبوعي** لدقائق الدراسة، وإحصاءات اليوم اللحظية.
- يعمل دون اتصال عبر عامل الخدمة (Service Worker) — يفتح آخر نسخة محفوظة.
- أمان قوي: عزل بيانات الطلاب عبر سياسات Row Level Security في قاعدة البيانات.

## إعداد قاعدة بيانات Supabase

1. أنشئ مشروعًا في Supabase.
2. من لوحة المشروع افتح SQL Editor، والصق محتوى `setup_supabase.sql` ثم شغّله. ينشئ ذلك جدول الجلسات وسياسات الوصول، بحيث يستطيع كل طالب التعامل مع جلساته فقط. (لا توجد خطوات إضافية — الهدف اليومي يُحفظ في بيانات المستخدم `user_metadata` ولا يحتاج جدولًا.)
3. من Connect أو إعدادات API انسخ Project URL ومفتاح Publishable.
4. افتح `supabase-config.js` وضع القيم مكان النصين التوضيحيين. هذا المفتاح عام ومناسب للواجهة؛ لا تضع مفتاح Secret في ملفات الموقع.
5. من **Authentication → URL Configuration**:
   - اضبط **Site URL** على رابط الموقع المنشور: `https://Omar1026.github.io/study-tracker/`
   - أضفه أيضًا إلى **Redirect URLs** (مطلوبة لروابط تأكيد البريد واستعادة كلمة المرور).
6. في إعدادات Authentication تأكد من تفعيل تسجيل الدخول بالبريد وكلمة المرور. إذا كان تأكيد البريد مفعلًا، ينشئ الطالب الحساب ثم يؤكد رسالة البريد قبل الدخول. رسائل التأكيد والاستعادة تُرسل عبر البريد الافتراضي للمشروع؛ للاستخدام الواسع اربط SMTP خارجيًا من نفس الإعدادات.

## نشر الموقع على GitHub Pages

ارفع ملفات المشروع إلى جذر المستودع، ثم من Settings → Pages اختر Deploy from a branch، والفرع `main` والمجلد `/(root)`. احفظ الإعداد وانتظر اكتمال النشر.

لا ترفع كلمات مرور المستخدمين أو أي مفتاح Secret. إعدادات Supabase المنشورة في `supabase-config.js` تشمل رابط المشروع ومفتاح Publishable فقط.

> عند تعديل ملفات الواجهة (`style.css` و`app.js` و`index.html`) ارفع رقم `CACHE` في `sw.js` حتى يحصل الزوّار على النسخة الجديدة فورًا.

## التطوير المحلي والفحوصات

- لا حاجة لأي خط بناء؛ افتح `index.html` مباشرة أو عبر أي خادم ثابت.
- فحوصات تلقائية تعمل مع كل دفع عبر GitHub Actions (`.github/workflows/ci.yml`): فحص صياغة JavaScript وصحة HTML. يمكنك تشغيلها محليًا:

```powershell
node --check app.js
npx htmlhint index.html
```

## بنية المشروع

| الملف | الوصف |
|-------|-------|
| `index.html` | بنية الصفحة (RTL عربي) |
| `style.css` | الأنماط، منسقة ومقسمة بتعليقات |
| `app.js` | منطق التطبيق بالكامل |
| `supabase-config.js` | رابط المشروع ومفتاح Publishable |
| `setup_supabase.sql` | إنشاء الجدول وسياسات RLS |
| `manifest.json` + `sw.js` + `icons/` | دعم PWA والعمل دون اتصال |
