# متابع الدراسة

## إعداد قاعدة بيانات Supabase

1. أنشئ مشروعًا في Supabase.
2. من لوحة المشروع افتح SQL Editor، والصق محتوى `setup_supabase.sql` ثم شغّله. ينشئ ذلك جدول الجلسات وسياسات الوصول، بحيث يستطيع كل طالب التعامل مع جلساته فقط.
3. من Connect أو إعدادات API انسخ Project URL ومفتاح Publishable.
4. افتح `supabase-config.js` وضع القيم مكان النصين التوضيحيين. هذا المفتاح عام ومناسب للواجهة؛ لا تضع مفتاح Secret في ملفات الموقع.
5. في إعدادات Authentication تأكد من تفعيل تسجيل الدخول بالبريد وكلمة المرور، وحدد رابط الموقع المنشور ضمن Site URL/Redirect URLs عند الحاجة. إذا كان تأكيد البريد مفعلًا، ينشئ الطالب الحساب ثم يؤكد رسالة البريد قبل الدخول.

## نشر الموقع على GitHub Pages

ارفع `index.html` و`style.css` و`app.js` و`supabase-config.js` إلى جذر المستودع، ثم من Settings → Pages اختر Deploy from a branch، والفرع `main` والمجلد `/(root)`. احفظ الإعداد وانتظر اكتمال النشر. يمكن الاحتفاظ بملف `setup_supabase.sql` وREADME في المستودع أيضًا.

لا ترفع كلمات مرور المستخدمين أو أي مفتاح Secret. إعدادات Supabase المنشورة في `supabase-config.js` تشمل رابط المشروع ومفتاح Publishable فقط، ويعتمد عزل بيانات الطلاب على سياسات Row Level Security في قاعدة البيانات.
